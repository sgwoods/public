# Google Canada Local HTML Archive

This folder contains checked-in local HTML preservation files for the Google
Canada era archive.

Expanded baseline on `2026-05-11`:

- `uwaterloo-entrepreneurial-computer-scientist.html`
- `google-canada-unboxing-2016.html`
- `google-canada-innovation-nation.html`
- `uwaterloo-cheriton-symposium-2017.html`
- `springboard-google-canada-interview.html`
- `citynews-google-lang-tannery.html`
- `betakit-joins-inovia-2021.html`
- `university-affairs-google-canada-interview-reader.html`
- `inovia-welcomes-steven-woods.html`

These files were localized from the Steven archive layer so the Google Canada
archive can restart cleanly as an era-specific archive in its own right, with a
better interview/media floor and a more explicit transition bridge.

The University Affairs file is intentionally a reader-style preservation copy,
because the archived page was browser-readable during capture but raw
non-browser fetches returned a `401 Authorization Required` shell.
