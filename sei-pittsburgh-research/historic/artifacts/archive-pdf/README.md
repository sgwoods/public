# SEI Pittsburgh Local PDF Archive

This folder contains checked-in local PDF preservation files for the SEI
Pittsburgh era archive.

Seeded baseline on `2026-05-11`:

- `perils-and-joys-of-reconstructing-architectures-1999-sei.pdf`
- `sei-architecture-practices-propel-successful-startup-2002.pdf`
- `software-architectural-transformation-1999-sei.pdf`
- `why-reengineering-projects-fail-1999-sei.pdf`

The first two files were preserved directly from SEI-hosted PDF URLs.

The latter two were preserved from the SEI library pages' `Download PDF` links.

Together they give the SEI archive a stronger restartable paper-and-bridge
floor of its own.
