# SEI Pittsburgh Local HTML Archive

This folder contains checked-in local HTML preservation files for the SEI
Pittsburgh era archive.

Seeded baseline on `2026-05-11`:

- `news-at-sei-september-1999.html`
- `steve-woods-sei-author-profile.html`
- `jeromy-carriere-sei-author-profile.html`
- `internetnews-another-feather-in-aols-cap-2000.html`

These files provide SEI-hosted institute context for the archive:

- the September 1999 newsletter issue page that frames the initial paper floor
- the current SEI author profile that explicitly identifies Steve Woods as an
  SEI alumni employee and clusters his publication record
- the current SEI author profile for Jeromy Carriere, which gives collaborator
  and institute context for the SEI-to-Quack transition lane
- the localized Quack-era acquisition coverage `Another Feather In AOL's Cap`,
  copied from the Quack archive with provenance so SEI can mark the AOL bridge
  while Quack keeps company-specific deep ownership
