Preserved artifacts, captures, and stable research material for the SEI
Pittsburgh era live here.

Current structure:

- `historic/artifacts/archive-html/` for preserved local HTML captures
- `historic/artifacts/archive-pdf/` for preserved local PDF captures

The current expanded baseline uses direct SEI-hosted PDFs where available,
stable SEI-hosted HTML pages for institute context, and one explicitly
localized bridge capture from Quack's artifact lane so the SEI archive can
restart in its own right.

One preserved SEI newsletter PDF currently supports two approved transition
source entries because it contains both the main architecture-practices feature
and the Quack-history sidebar.
